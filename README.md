## 🛠️ Tech Stack & Architecture

- **Core**: Semantic HTML5, Modular CSS3 (Custom Design Tokens, Glassmorphism, Bento Grid UI), Vanilla ES6 JavaScript
- **Atmospheric Background**: Lightweight 60fps 2D HTML5 Canvas sparkling particle engine (`particles.js`)
- **Theme**: Signature Amethyst Purple (`#a06cd5`, `#c084fc`, `#e2cfea`) on Deep Obsidian Void (`#040207`)

## 📁 Project Structure

```
├── index.html          # Semantic single-page HTML markup
├── README.md           # Project documentation
├── css/
│   ├── style.css       # Master stylesheet entry point
│   ├── tokens.css      # Design tokens, color palette, typography & curves
│   ├── base.css        # Base reset, ambient aura lights & custom cursor
│   ├── layout.css      # Floating glass capsule navbar, hero & sections
│   └── components.css  # Bento cards, UI kit filter tabs, skills & credentials
└── js/
    ├── main.js         # ES6 application bootstrap entry point
    ├── particles.js    # 2D canvas twinkling purple particle engine
    └── ui.js           # Navigation, scroll spy, filter tabs & clipboard interactions
```
